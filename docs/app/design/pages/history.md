# History Page Spec

## 1. 页面目的

`历史记录` 页面用于审计和回看用户主动触发的性能计算。记录仅保存在当前浏览器或 Tauri WebView 的 `localStorage`，不上传到服务器。

## 2. 写入时机

- 用户在性能计算页点击 `计算性能`
- 输入校验通过
- 计算引擎成功返回结果

应用初始默认计算、切换模型和重置操作不写入历史。

## 3. 记录字段

- 唯一 ID
- ISO 计算时间
- 模型 ID、模型 family、显示名称
- 完整 `PlatformInput` 参数快照
- 完整 `WorkloadInput` 参数快照
- `PerformanceSummary` 结果：
  - TTFT
  - Prefill TPS
  - Decode TPS
  - 运行时显存
  - Prefill / Decode 瓶颈
  - 显存是否满足容量

不保存 token sweep、公式追踪等大体积派生数据，避免 localStorage 快速膨胀。

## 4. 筛选与排序

- 模型筛选：全部模型或历史中出现过的具体模型
- 时间顺序：最新优先、最早优先
- 顶部显示当前可见记录数和总记录数

筛选和排序只改变页面显示，不修改持久化数据的内容。

## 5. 记录详情

列表默认显示：

- 计算日期
- 模型名
- Prefill TPS
- Decode TPS
- 运行时显存

点击记录可展开参数快照和完整结果摘要。所有记录默认收起。

## 6. 清空记录

- 无记录时按钮禁用
- 清空前显示不可撤销确认
- 确认后同时清除内存状态和 localStorage
- 清空后模型筛选恢复为全部模型
- 每条展开后的记录提供“删除此记录”按钮
- 删除单条记录前显示包含计算日期和模型名称的不可撤销确认
- 确认删除后同步更新内存状态和 localStorage，不影响其余记录

## 7. 响应式布局

- 桌面：筛选器横向排列，记录参数和结果采用双列
- 平板：工具栏纵向堆叠
- 手机：筛选、指标和详情均使用单列
